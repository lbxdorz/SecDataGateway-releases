# SecDataGateway 操作手冊

本站提供 **Windows** 與 **Mac** 的客戶圖文操作說明（安裝、接入本機 IDE、授權激活、脫敏驗證示例）。

| 平台 | 說明 |
| --- | --- |
| [Windows 操作手冊](windows/) | 下載 `windows_amd64.zip`、解壓、啟動、接入 IDE、導入授權 |
| [Mac 操作手冊](mac/) | 下載對應 `darwin_*` 包、解壓、移除隔離標記、啟動、接入 IDE、導入授權 |

## 下載與 AI 安裝

- **安裝包發佈頁：** [GitHub Releases](https://github.com/lbxdorz/SecDataGateway-releases/releases)
- **用 AI 助手安裝到授權頁：** 見倉庫 [README（繁中）](https://github.com/lbxdorz/SecDataGateway-releases/blob/main/README.zh-Hant.md) / [简体](https://github.com/lbxdorz/SecDataGateway-releases/blob/main/README.zh-CN.md) / [English](https://github.com/lbxdorz/SecDataGateway-releases/blob/main/README.md)
